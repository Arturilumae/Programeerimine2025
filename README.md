# Programmi kirjeldus
See programm arvutab ja analüüsib erinevate ainete hindu. Hetkel on programmi andmebaasis järgmised 5 ainet:
1) Programeerimine 1
2) Arvuti arhitektuur ja riistvara 1
3) Operatsioonisüsteemid
4) Kõrgem matemaatika 1
5) Sissejuhatus erialasse

# Nõuded programmi käivitamiseks:
Python (soovitatav versioon 3.7 või uuem)  
Vajalikud python teegid: pandas ja openpyxl  
# Programmi käivitamine:  
Võimalik on kasutada programmeerimisplatvormi (nt Thonny või Visual Studio Code)  
Või käsurealt, käivitades: "python main.py"
